# React Native starter app requirements

## Problem

There is no application project in this workspace. A runnable React Native foundation is needed so development can begin on a native mobile app.

## Requirement

Provide a new React Native project that can be installed and launched with the standard development workflow. It must include a simple, polished home screen and bottom navigation between Home and Setting.

## Acceptance Criteria

- [ ] The workspace contains a complete React Native project with the required package manifest and platform configuration.
- [ ] A developer can install dependencies and start the project using documented commands.
- [ ] The initial app renders a clear starter screen in an iOS simulator, Android emulator, or Expo Go-compatible development environment.
- [ ] The app provides a bottom bar with selectable Home and Setting tabs, and each tab presents its corresponding screen.
- [ ] The project includes concise setup and run instructions.

## Constraints

- Use a current, supported React Native development approach that works on both iOS and Android.
- Keep the initial application intentionally small and free of product-specific functionality.
- Do not require credentials, backend services, or device-specific configuration to run the starter screen.

## Non-Goals

- Authentication, API integration, persistence, multi-stack navigation, and production release configuration.
- A custom design system or feature-complete product UI.
- Unnecessary feature flags, environment variables, fallback modes, or compatibility layers.
